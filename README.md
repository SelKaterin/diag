# Процесс предоставления академического отпуска (AS-IS)

Диаграмма процесса (Mermaid):

```mermaid
flowchart TD
    %% Пул 1: Студент
    subgraph Студент ["Студент"]
        direction TB
        S1([Старт])
        T1[Подача заявления]
        T2[Предоставление документов]
        I1((Ожидание))
        T3[Получение уведомления]
        E1([Конец])
        S1 --> T1
        T1 --> T2
        T2 --> I1
        I1 --> T3
        T3 --> E1
    end

    %% Пул 2: Деканат
    subgraph Деканат ["Единый деканат"]
        direction TB
        T4[Прием документов]
        T5[Проверка документов]
        T6[Ввод данных в 1С Университет]
        T7[Создание приказа в 1С Университет]
        %% Убрали всё лишнее, никаких скобок, тире, переносов
        T8[Дублирование приказа в Документообороте]
        T9[Отправка на согласование]
        I2((Ожидание согласования))
        T10[Получение статуса подписания]
        T11[Обновление данных в 1С]
        T12[Проведение приказа в 1С]
        T13[Уведомление студента]
        E2([Конец])

        T4 --> T5
        T5 --> T6
        T6 --> T7
        T7 --> T8
        T8 --> T9
        T9 --> I2
